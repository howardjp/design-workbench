# Independent React documentation sites

Planned public homes, proposed by James on October 22, 2026:

| Family | Proposed home | Package |
| --- | --- | --- |
| Martlet | https://react.martletdesign.dev | @martlet/react |
| Krigsvold | https://react.krigsvolddesign.org | @krigsvold/react |

Each site should provide its own installation guide, component API/state documentation, interactive playground, patterns, application examples, release notes, accessibility results and known limits. Each build must include only its family package/styles/fonts and preserve the adopted family charter. Shared contracts, example data and behavioral tests can remain in the common source repository. Independent build/deploy targets do not require independent repositories; package or repository extraction remains possible later without changing their public identities.

The local registry remains the comparative administration consumer. Public documentation/playgrounds need their own honest example-data and persistence contract; they must not implicitly expose the unauthenticated SQLite service. These domains/build targets are a recorded direction, not claims of DNS setup, deployed sites or published npm packages.
