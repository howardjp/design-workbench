# Independent registry adoption observations

These are the original core 2.2.0 / Astro 1.2.0 observations, retained before remediation. They describe the conditions at the time, including the then-unavailable hosted MCP and the Krigsvold accent defect. They are evidence of the findings, not current release instructions. Registry lockfiles pin actual downloaded tarballs. Revalidation results for later versions are recorded separately. Local fixture paths in the raw findings identify their original execution location.
