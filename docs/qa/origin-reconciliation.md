# Origin reconciliation — October 24, 2026

The October 23 audit is a fixed baseline. This implementation applies its source-object decisions, removes unsupported decoration, and labels necessary application behavior as extension work. It does not lock either grammar or establish complete origin coverage. Theme 2.1.0 and React snapshot 0.1.0 remain unchanged and unpublished; application grammar/decision profiles are experimental 0.2.

Origin evidence remains pinned to Martlet `k3jph/k3jph.github.io@32b7166a629ea696147d0d779d911b713e4baf7e` and Krigsvold `basuhoward/krigsvold.org@a3cf072c516c59ed35814e0fa153028cc91ceecd`. The [baseline audit](origin-audit-2026-10-23.md) contains source citations, verified inventory and browser observations. Do not regenerate that inventory to disguise the original differences.

Implementation: `packages/*-react/src/{styles.css,index.tsx}`, `docs-app/src/layouts`, `docs-app/src/patterns`, and live/copy examples. Exact active source roles and boundaries appear in [Martlet decisions](../languages/martlet/decisions.md) and [Krigsvold decisions](../languages/krigsvold/decisions.md). Both MCP catalogues expose those profiles as `decisions`; each catalogue now has 53 resources. Builder skills include the same profiles and require source/translation/extension reasoning.
