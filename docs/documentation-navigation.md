# Documentation navigation

Owner direction, 25 October 2026: the design homes and React references use white navigation in light mode. In dark mode the same grey surface extends across the full viewport width. The header is a continuous band, with bounded content rather than a floating card.

This supersedes the earlier documentation-host translation of the origin mastheads. It does not change the origin websites or prescribe a universal application frame. Martlet retains its Cinzel identity, Lato navigation and gold current-page rule. Krigsvold retains its Roboto Slab identity, uppercase Roboto labels, white desktop dropdowns and in-flow mobile submenus. Light-mode text, hover and focus colors must remain legible on white.

The reference grey is sampled from the existing Krigsvold navigation surface. It is a documentation surface, not a replacement family palette. Existing homepage specimen appearance controls also change that home's navigation band; they retain their existing specimen scope.
