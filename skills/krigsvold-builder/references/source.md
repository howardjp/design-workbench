# Source and framework support

Canonical guidance: https://github.com/krigsvoldtheme/npm/tree/5deb567f7afcd8bedb50f9ea3f3fb501bc2ae7a8. The bundled grammar and source decisions are exact copies of that revision; implementation.json records framework availability. Grammar 0.3 remains experimental.

Core and Astro 2.2.x/1.2.x guidance is experimental. Check the separately verified distribution record in the connected MCP manifest and npm dist-tags before selecting exact versions. React 0.1.0 uses theme 2.1.0; read react-setup.md for its pinned npm installation and alternative public archive checksum. Read native-html.md and form-styling.md for supported core markup. Copied component examples are React examples. Read astro.md for Astro APIs. Shared grammar does not imply shared props or event/focus APIs.

The hosted read-only endpoint is https://krigsvolddesign.dev/mcp when available. The skill directory contains instructions and references only. The optional full agent archive contains a stdio server for offline/local transport; installing the skill does not install that server or create a remote connection. Check manifest family, sourceCommit and sourceDigest. Manual accessibility, localization/RTL and sustained use remain open.
